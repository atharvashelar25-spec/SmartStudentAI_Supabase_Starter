PROJECT OVERVIEW

About StudentAI

A beginner-friendly academic analytics and career-readiness project.
◈

Academic prediction

Uses attendance, previous marks, assignments, internal marks, study hours, and completed assignments to calculate a clearly labelled baseline estimate.

▤

Resume analysis

Extracts readable PDF text in the browser and uses transparent keyword rules to identify skills and resume sections.

⌕

Job matching

Compares extracted skills against example role requirements, showing matched skills and gaps.

Important limitations

This is a learning starter, not a validated academic decision system. The score formula is a baseline rather than a trained ML model. Browser PDF text extraction can fail on scanned PDFs; OCR and a private server-side extraction pipeline would be needed for those documents. Sample jobs are not live vacancies.
